### ❓ "No recuerdo la sintaxis"

```
🔍 Abre: [REFERENCIA_RAPIDA.md](REFERENCIA_RAPIDA.md)

Escribe: lo que buscas (ej: "arrays", "loops", "clases")
```

### ❓ "¿Cómo ejecuto un archivo?"

```
Con GNU Smalltalk instalado:
   gst archivo.st

Con TinyImageII:
   1. Abre http://tinyimage.org
   2. Copia el código
   3. Presiona Ctrl+D
```

### ❓ "¿Cómo creo mis propios programas?"

```
1️⃣  Abre editor en VSCode
2️⃣  Crea archivo: miprogram.st
3️⃣  Escribe código (consulta REFERENCIA_RAPIDA.md)
4️⃣  Ejecuta: gst miprogram.st
5️⃣  Edita y repite
```
