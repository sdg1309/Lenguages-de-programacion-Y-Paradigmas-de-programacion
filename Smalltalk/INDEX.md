## 🎯 EMPIEZA AQUÍ (Elige una opción)

### ⚡ Opción A: SIN instalar (2 minutos)

1. Ve a: **http://tinyimage.org**
2. Escribe:
```smalltalk
'🎉 Hola Smalltalk!' displayNl.
```
3. Presiona: **Ctrl+D**

✅ **Listo.** Ya tienes Smalltalk funcionando.

### ⚙️ Opción B: Instala GNU Smalltalk (5 minutos)

En la terminal de Codespaces:
```bash
cd ~/Smalltalk
bash install-smalltalk.sh
gst ejemplos_basicos.st
```

✅ **Listo.** Ejecuta cualquier archivo `.st`
