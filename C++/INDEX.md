## 💡 ¿Por qué aprender C++?

✅ Uno de los lenguajes más usados en la industria
✅ Rendimiento extremadamente alto (sistemas, juegos, HFT)
✅ Control total sobre la memoria y recursos
✅ Estándar moderno (C++17, C++20)
✅ Transferible a sistemas embebidos
✅ Excelente para estructuras de datos y algoritmos

---

## 🔧 Requisitos

- ✅ **Codespaces**: Ya tiene g++/clang++
- ✅ **Localmente**: `apt-get install g++` (Linux) o `brew install gcc` (macOS)
- ✅ **Windows**: Descarga MinGW o Visual Studio Community

---

## 🎓 Conceptos que aprenderás

### Básico
- Variables y tipos de datos
- Operadores y expresiones
- Control de flujo (if, loops)
- Funciones

### Intermedio
- Punteros y referencias
- Arrays y strings
- Estructuras de datos básicas
- Entrada/salida

### Avanzado
- Programación Orientada a Objetos (POO)
- Clases, herencia, polimorfismo
- Plantillas (templates)
- STL (Standard Template Library)
- Gestión de memoria (new/delete)
